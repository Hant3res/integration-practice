# Отчёт об устранении дефектов

## Дефект №1: При ошибке оплаты заказ остаётся в статусе "NEW"

| Поле | Значение |
|------|----------|
| **Описание** | При симуляции ошибки оплаты (недостаточно средств, отказ банка) заказ не отменяется, а остаётся в статусе NEW |
| **Серьёзность** | Высокая (High) |
| **Шаги воспроизведения** | 1. Добавить товар в корзину<br>2. Запустить Saga с payment_method="CARD"<br>3. Симулировать ошибку оплаты |
| **Ожидаемое поведение** | Заказ должен быть отменён, выполнена компенсация |
| **Фактическое поведение** | Заказ остаётся в статусе NEW, компенсация не вызывается |

### Локализация причины
В методе `_process_payment` Saga оркестратора при ошибке оплаты не вызывалась компенсация. Ошибка в логике обработки исключений.
